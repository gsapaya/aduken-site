# AGENTS.md — Aduken Site

## Propósito

Este repositorio contiene exclusivamente el sitio institucional y comercial de Aduken.

No contiene la aplicación ERP, la API ni lógica transaccional.

## Reglas

- Priorizar SEO, velocidad, accesibilidad y claridad.
- Mantener el sitio mayormente estático.
- No agregar React salvo necesidad real.
- No incorporar dependencias innecesarias.
- No publicar secretos ni credenciales.
- No inventar funcionalidades.
- No modificar DNS ni Render desde código.
- Respetar los archivos dentro de `docs/brand`.
- Tratar a `docs/product-book` como la fuente principal de posicionamiento, contenido y narrativa del sitio.
- No inventar mensajes, funcionalidades ni estructuras si no están especificadas en `docs/product-book`.
- Toda implementación debe indicar el archivo de especificación utilizado.
- Traducir el contenido técnico a beneficios comprensibles para el usuario final.
- La Home no debe implementarse todavía.
- Cualquier implementación futura de la Home debe respetar `docs/product-book/17-home-wireframe.md`.
- No publicar métricas, testimonios ni funcionalidades no verificadas.
- La propuesta de uso previo al acuerdo requiere condiciones operativas aprobadas.
- Mantener los textos comerciales editables.
- Al terminar una tarea, resumir archivos modificados y validaciones.
