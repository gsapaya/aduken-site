# AGENTS.md — Aduken Site

## Propósito

Este repositorio contiene exclusivamente el sitio institucional y comercial de Aduken.

No contiene la aplicación ERP, la API ni lógica transaccional.

## Reglas

- Priorizar SEO, velocidad, accesibilidad y claridad.
- Mantener el sitio mayormente estático.
- No agregar React salvo necesidad real.
- No incorporar dependencias innecesarias.
- No publicar secretos ni credenciales.
- No inventar funcionalidades.
- No modificar DNS ni Render desde código.
- Respetar los archivos dentro de `docs/brand`.
- Mantener los textos comerciales editables.
- Al terminar una tarea, resumir archivos modificados y validaciones.
