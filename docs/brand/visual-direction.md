# Dirección visual — Aduken

## Concepto

Energía contenida y precisa: potencia concentrada, no una explosión descontrolada.

## Recursos visuales

- Energía circular.
- Movimiento hacia adelante.
- Profundidad.
- Brillo controlado.
- Formas simples con presencia.
- Contrastes altos.
- Espacio visual generoso.

## Evitar

- Estética gamer explícita.
- Exceso de neón.
- Copiar elementos protegidos de Street Fighter.
- Ilustraciones genéricas de stock.
- Demasiadas tarjetas.
- Gradientes usados sin criterio.
