# Definición de terminado

La primera versión pública está lista cuando:

- La Home funciona en móvil y escritorio.
- Tiene mensaje, beneficios y CTA.
- Ingresar abre `https://app.aduken.ar`.
- El formulario de demo funciona.
- Existe contacto.
- Existen privacidad y términos.
- No se anuncian funciones inexistentes.
- El logo está en SVG.
- Las imágenes están optimizadas.
- `npm run build` termina correctamente.
- Render despliega desde `main`.
- `www.aduken.ar` funciona por HTTPS.
- `aduken.ar` redirecciona al dominio principal.
