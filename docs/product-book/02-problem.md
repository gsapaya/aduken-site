# 02 — El problema

## Problema del mercado

Existen muchos sistemas de gestión. El problema no es la falta de software.

Con frecuencia:

- el producto está lejos de la realidad del usuario;
- la mesa de ayuda conoce pantallas, pero no comprende el negocio;
- hablar con una persona preparada resulta difícil;
- las respuestas se limitan a “así funciona el sistema”;
- el usuario termina cambiando su operación para adaptarse al producto;
- importar datos o personalizar procesos exige conocimientos técnicos;
- las actualizaciones generan miedo porque pueden romper adaptaciones anteriores.

## Consecuencia

El sistema, que debería facilitar el trabajo, se convierte en una nueva fuente de esfuerzo. El usuario termina usando planillas paralelas, repitiendo tareas, creando atajos informales o resignando procesos que necesita.

## Oportunidad

Aduken puede diferenciarse no sólo por sus funciones, sino por su forma de comprender, acompañar y resolver.
