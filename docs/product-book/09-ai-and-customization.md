# 09 — Inteligencia artificial y personalización

## Principio

La inteligencia artificial debe resolver complejidad, no crear una nueva capa de complejidad.

## Ejemplo principal: lista de proveedor en Excel

Experiencia deseada:

1. El usuario carga el archivo.
2. Aduken analiza la información.
3. Identifica productos, códigos, precios y posibles inconsistencias.
4. Propone alternativas comprensibles.
5. Explica qué ocurrirá.
6. Pide confirmación.
7. Ejecuta el proceso.
8. Informa el resultado y los casos pendientes.

El usuario no debería tener que conocer la estructura interna del sistema, mapear columnas sin ayuda, entender relaciones técnicas ni modificar el archivo repetidas veces.

## Personalización

Aduken debe poder ofrecer comportamientos específicos para cada cliente cuando la operación lo justifique. La personalización debe estar aislada, documentada, poder probarse, convivir con el producto común y mantenerse frente a nuevas versiones.

## Mensaje público

> Aduken puede adaptarse a necesidades particulares y validar cada cambio para seguir evolucionando con seguridad.
