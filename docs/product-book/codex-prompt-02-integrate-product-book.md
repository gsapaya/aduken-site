# Prompt para Codex — Integrar Product Book

Trabajá únicamente dentro del repositorio `aduken-site`.

Objetivo:

Incorporar la carpeta `docs/product-book` como fuente de verdad del sitio, sin implementar todavía nuevas páginas ni rediseñar la Home.

Tareas:

1. Leer todos los archivos de `docs/product-book`.
2. Actualizar `AGENTS.md` para indicar que:
   - `docs/product-book` es la fuente principal de posicionamiento y contenido;
   - no se deben inventar mensajes, funcionalidades ni estructuras;
   - toda implementación debe indicar el archivo de especificación utilizado;
   - el contenido técnico debe traducirse a beneficios comprensibles.
3. Actualizar `README.md` con una sección “Product Book”.
4. No modificar componentes, páginas ni estilos salvo referencias rotas.
5. No implementar todavía las páginas de producto, demo ni contacto.
6. Ejecutar las validaciones existentes.

Salida:

- Resumen breve.
- Archivos modificados.
- Resultado de validaciones.
- No imprimir archivos completos.
